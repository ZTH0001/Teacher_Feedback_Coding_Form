Teacher Feedback Observation Form

One form per observed lesson · One statement per event · 10 events per page

01 · Observation details

Dates: DD/MM/YYYY. Enter / Shift+Enter or Tab / Shift+Tab move between fields. Use Lesson and Trial to identify the session, e.g. L1T1.

Observed minutes are calculated from lesson start and end times. If the observed duration differs (e.g. pauses), enter an override. This duration is used for praise rate per minute; it is not inferred from event timestamps.

02 · Category definitions & coding rules
CodeCategoryDefinitionExample

Digital layout: each page contains 10 events. Yellow rows are events 1, 6, 11, … and require an audio timestamp in mm:ss. A heavier line follows each block of five events. Additional pages can be added beyond the paper form’s 150 lines.

03 · Coding grid

Keyboard guide — Windows & MacBook

Windows Alt = MacBook Option (⌥). Enter is labelled Return (↵) on many Mac keyboards. Tab (⇥), Shift (⇧), Space and arrow keys work on both. Mac Delete (⌫) clears the focused code; Windows Delete or Backspace does the same.

Tab / Shift+Tab reach all controls. Alt + arrow keys move between visible controls while text fields retain normal editing. Alt+1: Observation details; Alt+2: Codebook; Alt+3: Coding; Alt+4: Summary; Alt+5: Save/export. Closed sections open automatically.

In coding cells: Left / Right move between time, code choices, Name and Clear; Up / Down move between events. Press 1–5 to select BSP-T, BSP-C, GP, CF or R. Enter / Space selects a focused button. After selection, enter a name if applicable, or leave it blank; Enter in Name confirms the event and moves to the next row. If a required timestamp is missing, focus moves there first. Enter in a timestamp field moves to the code choices or Name. In text fields, Alt + arrow keys navigate without interrupting typing.

Code every teacher statement once. Praise plus correction = two consecutive events. Enter audio time on yellow rows as mm:ss (e.g. 02:37 = 2 min 37 s). Enter a first name only when a single student is addressed by first name; leave Name blank for the whole class or a group.

An event is complete when one code is selected and its checkpoint timestamp is valid, if required. Name is optional. Press Enter in Name to finish the row; after 10 complete events, the next page opens automatically. Review or edit any page without losing entries.

04 · Frequency summary

Only complete events enter counts, percentages and ratios. Incomplete entries remain saved and are exported with their status. Each statement contributes to one category only.

Summary and ratios

With no denominator events, a ratio is shown as “not defined”; it is not reported as zero. Praise rate requires a positive observed duration. The source form’s praise-to-reactive target is at least 4:1; it is not assessed when no reactive statements are recorded.

06 · Save and export

Default filename: TF_LessonTrial_Date_Observer, e.g. TF_L1T1_06NOV26_AB.xlsx. TF = Teacher Feedback. Lesson 1, Trial 1 = L1T1. Edit the suggested name in the prompt before downloading. Fill Lesson and Trial to replace LxTx in the suggested filename.

All data entry and processing happen in this browser. Export a JSON backup regularly; reopen it to continue later. Excel is for analysis and sharing. Save before starting a new session.
